# 🧺 Wasdag!

Een spelletje om te leren hoe je de was doet:

1. **Sorteren** – sleep kleren naar de juiste wasmand
2. **Wasmachine** – kies programma, temperatuur, centrifuge, wasmiddel en droogmethode
3. **Wasetiketten** – leer de wassymbolen
4. **Spiekbriefje** – alle regels op een rijtje

Spelen: https://jochemjanssens.github.io/wasdag/
